How can we control servos with Arduino?
In this code, you can control them without using any external library.
Servomotors interpretate PWM signal coming out from Arduino and they traduce it in a degrees value.
In this code there are two function: "Apertura()" and "Chiusura()". The first one moves the servo +90° and the second -90°.
You can modify the code to open the servo with other degrees values.
